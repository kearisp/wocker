# Файли збірки

> ℹ️ Ця можливість буде доступна, починаючи з Wocker v1.1.8.

Проєкт може перевизначати файли з пресета, а директорія даних проєкту своєю чергою може перевизначати файли з проєкту.

Це стосується проєктів, які використовують пресет у режимі **For project only** (`presetMode: project`), що обирається під час налаштування пресета для проєкту.

## Шари

Образ збирається з трьох шарів, об'єднаних в один контекст збірки, у порядку зростання пріоритету (останній — найвищий):

1. директорія пресета;
2. директорія проєкту;
3. директорія даних проєкту `<wocker-data-dir>/projects/<project-name>` (за замовчуванням `~/.workspace/projects/<project-name>`).

Якщо той самий файл є в кількох шарах, береться файл із шару з вищим пріоритетом. Це дозволяє перевизначити або додати файли (`php.ini`, конфіг, скрипт) для одного проєкту, не змінюючи пресет чи репозиторій проєкту.

```text
~/.workspace/projects/my-app/
├── config.json      # ігнорується, не потрапляє в контекст збірки
└── php.ini          # доступний у Dockerfile як `COPY php.ini ...`
```

## Примітки

- `config.json` проєкту завжди виключається з контексту збірки.
- `.dockerignore` у шарі застосовується лише до цього шару.
- Образ називається `project-<project-name>:develop`.
- У режимі **Global usage** використовується лише директорія пресета.
- Щоб перезібрати образ після зміни цих файлів, виконайте `ws start --build`.
