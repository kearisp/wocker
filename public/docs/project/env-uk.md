# Змінні середовища

Для кожного проєкту є можливість додати змінні середовища.

```shell
ws config [-n <name>] [-g] [-s <service>]
ws config:get <KEY> [...KEYS] [-n <name>] [-g]
ws config:set <KEY>=<value> [...KEY2=value2] [-n <name>] [-g] [-l] [-s <service>]
ws config:unset <KEY> [...KEYS] [-n <name>] [-g] [-l] [-s <service>]
```


## Шари

Змінні зберігаються в шарах. Якщо той самий ключ є в кількох шарах, перемагає шар з вищим пріоритетом:

| Шар        | Де зберігається                                         | Пріоритет |
|------------|---------------------------------------------------------|-----------|
| Data       | Власні дані Wocker для проєкту (ціль за замовчуванням)  | найвищий  |
| Repository | `wocker.config.json` у директорії проєкту               | середній  |
| Global     | Глобальні змінні, задані через `--global`               | найнижчий |

`config:set` і `config:unset` за замовчуванням записують у шар **Data**. Використайте `--local`, щоб записати в шар **Repository**, або `--global`, щоб змінити глобальні змінні.


## Список

```shell
$ ws config
┌────────────┬──────────────────────┬────────────┐
│ LAYER      │ KEY                  │ VALUE      │
├────────────┼──────────────────────┼────────────┤
│ Data       │ APACHE_DOCUMENT_ROOT │ /var/www   │
├────────────┼──────────────────────┼────────────┤
│ Repository │ EXAMPLE_VALUE        │ test-value │
└────────────┴──────────────────────┴────────────┘
```

Якщо ключ визначено в кількох шарах, рядки з нижчим пріоритетом позначаються `(Overridden)` і виводяться сірим. Вони показуються лише в інтерактивному терміналі; коли вивід перенаправлено або передано через pipe, друкуються тільки чинні значення.

Колонка `SERVICE` додається для проєктів типу `compose` (або коли увімкнено експериментальну функцію `projectComposeType`). Використайте `--service`, щоб показати змінні лише одного сервісу.

Використайте `--global`, щоб показати лише глобальні змінні.


## Одна змінна

```shell
$ ws config:get KEY
```

Виводить значення кожного запитаного ключа для кожного шару, де він визначений, у тому самому форматі таблиці, що й `ws config`. Якщо нічого не знайдено, виводить `No environment variables found.`


## Встановлення

```shell
$ ws config:set KEY=value KEY2=value2
$ ws config:set --local KEY=value
$ ws config:set --global KEY=value
```

Змінна без значення пропускається з попередженням.


## Видалення

```shell
$ ws config:unset KEY1 KEY2
$ ws config:unset --local KEY1
$ ws config:unset --global KEY1
```


## Опції

- `-n, --name <name>` — назва проєкту (за замовчуванням поточний проєкт).
- `-g, --global` — працювати з глобальними змінними замість проєкту.
- `-l, --local` — (`config:set`, `config:unset`) записувати в шар Repository (`wocker.config.json`) замість шару Data.
- `-s, --service <service>` — назва сервісу.
